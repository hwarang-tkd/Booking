# 花郎武道館 線上約課系統

讓學員用手機就能預約上課，老師在後台管理固定課表、看名單。
不需要安裝任何套件，只要 Node.js 22.5 以上。

第一次啟動時會自動載入花郎武道館目前的每週課表（`lib/schedule.js`），名額預設團體班 20 人、
幼兒期班 15 人、私人課 1 人，可在後台「固定課表」調整。

## 功能

**學員端**（`/`、`/my`、`/info`）
- 學員用**老師建立的信箱**登入（不用密碼、不用驗證碼），登入一次可維持半年
- 依日期瀏覽課程，可依類型篩選（成人跆拳道、兒童、幼兒、格鬥、黑帶、私人課），顯示剩餘名額
- 一鍵預約；已預約的課會標示「你已預約」
- 「我的預約」：即將上課、最近上過的課，一鍵取消（上課前 N 小時內不能線上取消，預設 2 小時）
- 「課表與收費」頁：每週課表（隨後台設定即時更新）、收費方式、地址

**老師後台**（`/admin`）
- 密碼登入（連續輸錯 5 次鎖 5 分鐘）
- **學員資料**：新增／編輯學員（姓名、信箱、電話、老師備註），可從 Excel／試算表整批貼上匯入；
  查看每位學員的預約紀錄、即將上課與已上堂數；停用的學員無法登入
- **固定課表**：設定每週固定的課，系統自動開放未來 4 週的預約；修改會套用到之後的課
- **停課**：國定假日或臨時休館，把那一堂設為停課（學員頁面會隱藏，已預約的人會看到「本堂停課」），也可以恢復
- **加開課程**：只上一次的特別班、檢定、補課
- 每週課表與名單（姓名、電話、信箱、備註、體驗課／代約標記）；幫學員代約、取消預約、修改單堂課程

> 登入只需要信箱，知道別人信箱的人可以用對方名義約課。對道館的使用情境通常足夠，
> 若需要更嚴格，可以改成寄送登入連結到信箱（需要設定寄信服務）。

## 快速開始

```bash
cp .env.example .env   # 編輯 .env，填入後台密碼
npm start
```

`.env` 已列在 `.gitignore`，密碼不會被上傳到 GitHub。也可以直接用環境變數：`ADMIN_PASSWORD=你的密碼 npm start`。

- 學生頁面：http://localhost:3000
- 老師後台：http://localhost:3000/admin

資料存在 `data/booking.db`（SQLite），備份這個檔案即可。

## 設定（環境變數）

| 變數 | 預設 | 說明 |
| --- | --- | --- |
| `ADMIN_PASSWORD` | （無） | 後台密碼，**必填**；沒設定時後台無法登入 |
| `SCHOOL_NAME` | `花郎武道館` | 顯示在頁面上方的名稱 |
| `SCHOOL_ADDRESS` | `台北市忠孝東路一段176號2樓之1` | 地址 |
| `SCHOOL_ADDRESS_NOTE` | `近善導寺捷運站 5 號出口` | 交通說明 |
| `FACEBOOK_URL` | （空） | FB 粉絲專頁網址，設定後頁面會出現連結 |
| `SEED_SCHEDULE` | `1` | 設為 `0` 則全新資料庫不自動載入預設課表 |
| `PORT` | `3000` | 伺服器埠號 |
| `DB_PATH` | `data/booking.db` | 資料庫位置 |
| `TIMEZONE` | `Asia/Taipei` | 課程時間所在時區 |
| `CANCEL_HOURS` | `2` | 上課前幾小時內不能線上取消 |
| `BOOK_CUTOFF_MINUTES` | `0` | 上課前幾分鐘停止預約 |
| `BOOK_AHEAD_DAYS` | `28` | 學生可預約未來幾天內的課 |

## 部署

任何能跑 Node.js 且有**永久儲存空間**的主機都可以（VPS、Railway、Render 加 Disk、Fly.io 加 Volume、家裡的 NAS）。

使用 Docker：

```bash
docker build -t booking .
docker run -d -p 3000:3000 -v booking-data:/data \
  -e ADMIN_PASSWORD=你的密碼 booking
```

正式上線請放在 HTTPS 後面（例如 Caddy、Nginx 或平台內建的 HTTPS），密碼才不會在網路上明文傳送。

## 第一次使用

1. 在 `.env` 設定 `ADMIN_PASSWORD` 後啟動，進入 `/admin`
2. 到「學員資料」→「批次匯入」，從試算表貼上「姓名、信箱、電話」
3. 到「固定課表」確認每堂課的名額
4. 把網址傳給學員，請他們用登記的信箱登入

## 修改收費

收費表在 `public/info.html`，直接編輯 HTML 即可。

## 專案結構

```

lib/db.js        SQLite 資料表與查詢（預約在交易中檢查名額，不會超賣）
lib/schedule.js  課程分類顏色與預設每週課表
lib/time.js      時區與日期工具
public/          前端頁面（預約 index、我的預約 my、課表與收費 info、後台 admin）
test/            API 測試
```
